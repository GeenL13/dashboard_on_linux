## 编译程序
1. 请先配置好交叉编译工具链
2. 开始编译，进入项目根目录后执行命令：
```
mkdir build
cd ./build
cmake ../
make
```

3. 运行程序
```
./candata_collect
```
## 基本功能
多通道采集汽车can数据，支持存储进SD卡以及对数据进行进一步处理
